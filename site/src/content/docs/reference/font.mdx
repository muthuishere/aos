<p class="cmd-lead">Installed fonts</p>

2 commands. Run `aos font --help` for the same list from the binary, or [see every group](../commands/).

Installed font families and the directories they are read from. `list` is what `draw --font` and `subtitle --font` accept. No display is needed.

## Commands

### aos font dirs

<p class="cmd-lead">Print the directories fonts are read from</p>

```sh
aos font dirs
```

```sh
aos font dirs
```

### aos font list

<p class="cmd-lead">List installed font families</p>

```sh
aos font list [filter]
```

```sh
aos font list
aos font list mono
```
