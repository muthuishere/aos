<p class="cmd-lead">Open a site as a standalone browser window</p>

1 command. Run `aos webapp --help` for the same list from the binary, or [see every group](../commands/).

Open a URL in a chromeless browser window, so a web app behaves like a native one for `window` commands. Needs a Chromium-based browser or Edge.

## Commands

### aos webapp open

<p class="cmd-lead">Open a URL in a chromeless app window</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos webapp open <url>
```

| flag | values | meaning |
|---|---|---|
| `<url>` | | Required positional argument |

```sh
aos webapp open https://app.slack.com
```
