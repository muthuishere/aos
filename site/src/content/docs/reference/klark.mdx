### aos klark feed

<p class="cmd-lead">Add a feed: send new output of a command, file or poll to an agent</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)

```sh
aos klark feed <agent> <instruction> --stream|--follow|--poll <source> [options]
```

| flag | values | meaning |
|---|---|---|
| `<agent>` | | Required positional argument |
| `<instruction>` | | Required positional argument |
| `<source>` | | Required positional argument |
| `--stream` |  | One of these is required |
| `--follow` |  | One of these is required |
| `--poll` |  | One of these is required |

```sh
aos klark feed work/rev "Look at new errors" --follow app.log
```
