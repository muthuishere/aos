<p class="cmd-lead">Do Not Disturb / Focus: read it, and set it where the OS allows</p>

3 commands. Run `aos focus --help` for the same list from the binary, or [see every group](../commands/).

Do Not Disturb, called Focus on macOS and Windows. `status` reads it on macOS (a Focus turned on by hand, from the Focus store; scheduled ones are not visible there) and on GNOME. `on` and `off` work on GNOME, where `--for=1h` turns banners back on by itself. macOS and Windows offer no supported API to set Focus, so there they exit 2 and say what to use instead. It follows the host: it is about the person at the screen.

## Commands

### aos focus off

<p class="cmd-lead">Turn Do Not Disturb off (GNOME)</p>

Under WSL / SSH: runs on the Windows host (the machine with the screen). [How the host works](../../host/)

```sh
aos focus off
```

```sh
aos focus off
```

### aos focus on

<p class="cmd-lead">Turn Do Not Disturb on, optionally for a while (GNOME)</p>

Under WSL / SSH: runs on the Windows host (the machine with the screen). [How the host works](../../host/)

```sh
aos focus on [--for=<duration>]
```

| flag | values | meaning |
|---|---|---|
| `--for` | `<duration>` | Optional |

```sh
aos focus on
aos focus on --for=1h
```

### aos focus status

<p class="cmd-lead">Print whether Do Not Disturb (Focus) is on, which mode, and until when</p>

Under WSL / SSH: runs on the Windows host (the machine with the screen). [How the host works](../../host/)

```sh
aos focus status [--json]
```

| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh
aos focus status
aos focus status --json
```
