### aos tab click

<p class="cmd-lead">Press a button or link in a browser tab's page, without moving the mouse</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span> <span class="cmd-badge">darwin · windows only</span></p>

```sh
aos tab click (--id=<tab id> | --url=<substring> | --title=<substring>) [--app=<name>] (--element=<ref> | --find=<label>) [--role=button|link|checkbox|radio|...] [--exact] [--nth=<n>] [--allow-focus]
```

| flag | values | meaning |
|---|---|---|
| `--id` | `<tab id>` | One of these is required |
| `--url` | `<substring>` | One of these is required |
| `--title` | `<substring>` | One of these is required |
| `--app` | `<name>` | Optional |
| `--element` | `<ref>` | One of these is required |
| `--find` | `<label>` | One of these is required |
| `--role` | `button`, `link`, `checkbox`, `radio`, `...` | Optional |
| `--exact` |  | Optional |
| `--nth` | `<n>` | Optional |
| `--allow-focus` |  | Optional |

```sh
aos tab click --id=chrome:1658108662:1658109078 --element=e8
aos tab click --title="Telegram" --find=Send --role=button
# exit 3 when nothing matches or the page changed, 4 when several elements match
```

| flag | values | meaning |
|---|---|---|
| `--id` | `<tab id>` | One of these is required |
| `--title` | `<substring>` | One of these is required |
| `--url` | `<substring>` | One of these is required |
| `--app` | `<name>` | Optional |
| `--kind` | `<kind>` | Optional |
| `--exact` |  | Optional |
| `--expect-title` | `<substring>` | Optional |

```sh
aos tab close --id=chrome:1658108662:1658109078
```
