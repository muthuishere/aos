<p class="cmd-lead">Desktop windows: list, focus, move, resize, arrange</p>

9 commands. Run `aos window --help` for the same list from the binary, or [see every group](../commands/).

Desktop windows on every platform: list them with geometry, focus one, move it to a zone or exact bounds, resize it, wait for one to appear, and save or apply a whole layout. Zones are `1A`/`1B` for halves, `2A` to `2D` for quarters and `M:N` for the M-th of N columns; `zones` shows them on a real monitor.

## Commands

### aos window arrange

<p class="cmd-lead">Apply a saved layout of many windows in one pass</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos window arrange <layout.json | ->
```

| flag | values | meaning |
|---|---|---|
| `<layout.json \| ->` | | Required positional argument |

```sh
aos window arrange ~/.config/aos/layouts/work.json
echo '[{"app":"Google Chrome","zone":"1A"},{"app":"Slack","zone":"1B"}]' | aos window arrange -
```

### aos window move

<p class="cmd-lead">Move a window to a zone, a split, or absolute bounds</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos window move <app> (--zone=<1A|2:1> | --at=<x,y,w,h>) [--monitor=<n>]
```

| flag | values | meaning |
|---|---|---|
| `<app>` | | Required positional argument |
| `--zone` | `1A`, `2:1` | One of these is required |
| `--at` | `<x,y,w,h>` | One of these is required. comma-separated |
| `--monitor` | `<n>` | Optional |

```sh
aos window move Chrome --zone=1B
aos window move Chrome --monitor=2 --zone=1:3
aos window move Slack --at=0,25,1920,1055
```

### aos window text

<p class="cmd-lead">Print all the text of a window, in reading order (accessibility, OCR fallback)</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos window text (<app> | --app=<name> | --title=<substring> | --id=<window id> | --focused) [--source=auto|accessibility|ocr] [--json] [--plain] [--max-chars=<n>] [--timeout=<ms>] [--raise]
```

| flag | values | meaning |
|---|---|---|
| `<app>` | | One of these is required |
| `--app` | `<name>` | One of these is required |
| `--title` | `<substring>` | One of these is required |
| `--id` | `<window id>` | One of these is required |
| `--focused` |  | One of these is required |
| `--source` | `auto`, `accessibility`, `ocr` | Optional |
| `--json` |  | Optional |
| `--plain` |  | Optional |
| `--max-chars` | `<n>` | Optional |
| `--timeout` | `<ms>` | Optional |
| `--raise` |  | Optional |

```sh
aos window text TextEdit
aos window text --focused --max-chars=4000
aos window text --app=Chrome --json
aos window text --id=12345 --source=ocr --raise   # OCR a covered window: brings it to the front, then hands focus back
# auto reads the accessibility tree (AX / UI Automation / AT-SPI) and falls back to OCR when it has almost no text
# exit 3 when no window matches
```
