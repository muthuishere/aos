### aos window arrange

<p class="cmd-lead">Apply a saved layout of many windows in one pass</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos window arrange <layout.json | ->
```

| flag | values | meaning |
|---|---|---|
| `<layout.json \| ->` | | Required positional argument |

```sh
aos window arrange ~/.config/aos/layouts/work.json
echo '[{"app":"Google Chrome","zone":"1A"},{"app":"Slack","zone":"1B"}]' | aos window arrange -
```

### aos window move

<p class="cmd-lead">Move a window to a zone, a split, or absolute bounds</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos window move <app> (--zone=<1A|2:1> | --at=<x,y,w,h>) [--monitor=<n>]
```

| flag | values | meaning |
|---|---|---|
| `<app>` | | Required positional argument |
| `--zone` | `1A`, `2:1` | One of these is required |
| `--at` | `<x,y,w,h>` | One of these is required. comma-separated |
| `--monitor` | `<n>` | Optional |

```sh
aos window move Chrome --zone=1B
aos window move Chrome --monitor=2 --zone=1:3
aos window move Slack --at=0,25,1920,1055
```
