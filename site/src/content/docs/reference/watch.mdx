<p class="cmd-lead">Follow what changes on this machine, one JSON line per event</p>

6 commands. Run `aos watch --help` for the same list from the binary, or [see every group](../commands/).

Follow changes as a stream of JSON lines: the clipboard, the focused window, or a file or directory. The first sample is a baseline, so `--max=1` means the next change. `watch clipboard` hides the text unless `--content` is passed. These run until interrupted and are not MCP tools.

## Commands

### aos watch camera

<p class="cmd-lead">Report when any app starts or stops using the camera</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span> <span class="cmd-badge">darwin · windows only</span></p>

```sh
aos watch camera [--until=busy|free] [--interval=<1s>] [--timeout=<duration>] [--json]
```

| flag | values | meaning |
|---|---|---|
| `--until` | `busy`, `free` | Optional |
| `--interval` | `<1s>` | Optional. default 1s |
| `--timeout` | `<duration>` | Optional |
| `--json` |  | Optional |

```sh
aos watch camera
aos watch camera --until=busy --timeout=10m
aos watch camera --until=free && echo 'call is over, start the build'
aos watch camera --json
# with --until: exit 0 when the state is reached (at once if it already is), 3 on --timeout
```

### aos watch tab

<p class="cmd-lead">Print a JSON line with the new text whenever a browser tab's page changes</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span> <span class="cmd-badge">darwin · windows only</span></p>

```sh
aos watch tab (--id=<tab id> | --url=<substring> | --title=<substring>) [--app=<name>] [--match=<text>] [--exact] [--interval=<1s>] [--timeout=<duration>] [--max=<n>]
```

| flag | values | meaning |
|---|---|---|
| `--id` | `<tab id>` | One of these is required |
| `--url` | `<substring>` | One of these is required |
| `--title` | `<substring>` | One of these is required |
| `--app` | `<name>` | Optional |
| `--match` | `<text>` | Optional |
| `--exact` |  | Optional |
| `--interval` | `<1s>` | Optional. default 1s |
| `--timeout` | `<duration>` | Optional |
| `--max` | `<n>` | Optional |

```sh
aos watch tab --id=chrome:1658108662:1658109078
aos watch tab --url=web.whatsapp.com --match="Build finished" --timeout=5m
# with --match: exit 0 when the text appears, 3 on --timeout or when the tab closes
```
