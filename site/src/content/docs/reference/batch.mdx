2 commands. Run `aos batch --help` for the same list from the binary, or [see every group](../commands/).

### aos batch

<p class="cmd-lead">Run a YAML list of steps (a file, - for stdin, or the YAML inline); everything is checked first</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)

```sh
aos batch <file.yaml | - | inline yaml> [--check] [--json]
```

| flag | values | meaning |
|---|---|---|
| `<file.yaml \| - \| inline yaml>` | | Required positional argument |
| `--check` |  | Optional |
| `--json` |  | Optional |

```sh
aos batch demo.yaml
aos batch --check demo.yaml
aos batch '[launch: calc, parallel: [say: seven, click: Calculator Seven], type: Notepad done]'
aos batch verbs   # every verb, generated from the commands
```
