<p class="cmd-lead">Bluetooth: radio state, paired devices, connect</p>

6 commands. Run `aos bluetooth --help` for the same list from the binary, or [see every group](../commands/).

The Bluetooth radio and paired devices. `status` and `list` work on macOS (system_profiler), Linux (bluetoothctl) and Windows (the classic Bluetooth API). `connect` and `disconnect` take a name, a unique part of one, or an address, and work on macOS (public IOBluetooth) and Linux. `on` and `off` work on Linux only: macOS and Windows have no public, dependency-free way to switch the radio, so those exit 2. It follows the host, since the headphones and keyboard belong to the person at the screen.

## Commands

### aos bluetooth connect

<p class="cmd-lead">Connect a paired device by name or address</p>

```sh
aos bluetooth connect <name|address>
```

| flag | values | meaning |
|---|---|---|
| `<name\|address>` | | Required positional argument |

```sh
aos bluetooth connect AirPods
aos bluetooth connect D1:08:D1:0E:60:DB
```
