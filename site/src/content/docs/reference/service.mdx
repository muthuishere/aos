<p class="cmd-lead">Run a command as a managed per-user OS service</p>

6 commands. Run `aos service --help` for the same list from the binary, or [see every group](../commands/).

### aos service create

<p class="cmd-lead">Install a command as a service</p>

```sh
aos service create <name> [--autostart] [--now] -- <command> [args...]
```

| flag | values | meaning |
|---|---|---|
| `<name>` | | Required positional argument |
| `<command>` | | Required positional argument |
| `--autostart` |  | Optional |
| `--now` |  | Optional |
| `--` |  | Required |

```sh
aos service create mcp --autostart --now -- aos serve mcp
aos service create nap -- /bin/sleep 60
```
