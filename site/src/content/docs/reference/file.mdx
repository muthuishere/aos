<p class="cmd-lead">Read, write, and inspect files</p>

9 commands. Run `aos file --help` for the same list from the binary, or [see every group](../commands/).

Read, write and inspect files with exit codes an agent can trust. `read` takes a line range, `write` and `append` take words or stdin, `list` and `stat` have `--json`. `delete` refuses filesystem roots, your home directory and system directories, and needs `--recursive` for a directory.

## Commands

### aos file append

<p class="cmd-lead">Append stdin, or the given words, to a file</p>

```sh
aos file append <path> [text...]
```

| flag | values | meaning |
|---|---|---|
| `<path>` | | Required positional argument |

```sh
aos file append log.txt "done"
```
