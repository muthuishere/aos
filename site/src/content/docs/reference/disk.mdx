<p class="cmd-lead">Volumes: free and total space, eject removable drives</p>

3 commands. Run `aos disk --help` for the same list from the binary, or [see every group](../commands/).

Mounted volumes and their space. `list` shows each volume with total, used and free space and whether it is removable; `usage` answers for the volume holding one path (your home folder by default). *Free* is what you can still write, the same number Finder, Explorer and `df` show as available. `eject` unmounts and ejects a removable drive (`diskutil` on macOS, `udisksctl` on Linux, the same calls Explorer uses on Windows) and refuses the system volume.

## Commands

### aos disk eject

<p class="cmd-lead">Unmount and eject a removable volume, by mount point or device</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)

```sh
aos disk eject <mount|device>
```

| flag | values | meaning |
|---|---|---|
| `<mount\|device>` | | Required positional argument |

```sh
aos disk eject /Volumes/USB
aos disk eject /dev/sdb1
aos disk eject E:
```

### aos disk list

<p class="cmd-lead">List mounted volumes with total, used and free space</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)

```sh
aos disk list [--json]
```

| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh
aos disk list
aos disk list --json
```

### aos disk usage

<p class="cmd-lead">Print total, used and free space of the volume holding a path</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)

```sh
aos disk usage [<path>] [--json]
```

| flag | values | meaning |
|---|---|---|
| `<path>` | | Optional positional argument |
| `--json` |  | Optional |

```sh
aos disk usage              # the volume holding your home folder
aos disk usage /Volumes/USB --json
aos disk usage D:\
```
