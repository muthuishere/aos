<p class="cmd-lead">Start applications</p>

1 command. Run `aos launch --help` for the same list from the binary, or [see every group](../commands/).

Start an application by name. `--wait` blocks until its window exists, so the next command can act on it. Unknown flags are passed through to the application on purpose.

## Commands

### aos launch

<p class="cmd-lead">Launch an application, optionally waiting for its window</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

Under WSL / SSH: runs on the Windows host (the machine with the screen). [How the host works](../../host/)

```sh
aos launch <app> [args...] [--wait[=<ms>]] [--or-focus]
```

| flag | values | meaning |
|---|---|---|
| `<app>` | | Required positional argument |
| `<ms>` | | Optional positional argument |
| `--wait` |  | Optional |
| `--or-focus` |  | Optional |

```sh
aos launch "Visual Studio Code"
aos launch Chrome --wait
aos launch Slack --or-focus   # raise Slack's window if it is open, else start it
```
