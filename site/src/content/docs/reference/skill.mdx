<p class="cmd-lead">The agent skill bundled in this binary</p>

4 commands. Run `aos skill --help` for the same list from the binary, or [see every group](../commands/).

The agent skill bundled in the binary. It installs itself to `~/.claude/skills/` and `~/.agents/skills/` on the first run and is refreshed with the binary; these commands install, print, locate or remove it by hand. See [using it from an agent (the skill)](/aos/agent-skill/).

## Commands

### aos skill install

<p class="cmd-lead">Install the bundled agent skill for every agent on this machine</p>

```sh
aos skill install [--json]
```

| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh
aos skill install
```

### aos skill path

<p class="cmd-lead">Print where `skill install` would write</p>

```sh
aos skill path
```

```sh
aos skill path
```

### aos skill show

<p class="cmd-lead">Print the bundled skill without installing it</p>

```sh
aos skill show
```

```sh
aos skill show
```

### aos skill uninstall

<p class="cmd-lead">Remove the installed agent skill</p>

```sh
aos skill uninstall [--json]
```

| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh
aos skill uninstall
```
