<p class="cmd-lead">Diagnostics for bug reports</p>

2 commands. Run `aos debug --help` for the same list from the binary, or [see every group](../commands/).

Diagnostics for a bug report. `debug` prints the platform, version, plugin directories and command counts; `debug tools` reports which helper programs such as ffmpeg, wmctrl or xdotool are installed. For a health check with fixes, use `aos doctor` instead.

## Commands

### aos debug

<p class="cmd-lead">Print a diagnostic dump: platform, tools, plugin dirs</p>

```sh
aos debug
```

```sh
aos debug
```

### aos debug tools

<p class="cmd-lead">Report which helper tools are installed</p>

```sh
aos debug tools
```

```sh
aos debug tools
```
