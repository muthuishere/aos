<p class="cmd-lead">Session power state: lock, sleep, restart, shutdown, logout</p>

7 commands. Run `aos system --help` for the same list from the binary, or [see every group](../commands/).

Session and power state. `info` prints OS and hardware facts and works everywhere. `lock`, `sleep`, `logout`, `restart` and `shutdown` do exactly what they say with no confirmation, so an agent should check with the person before the last three. `thermal` prints how hard the OS is throttling to stay cool (macOS: nominal, fair, serious, critical) and the temperatures it exposes: the battery on macOS, where die temperatures sit behind the private SMC, and every thermal zone on Linux. Windows keeps temperatures behind WMI, so `thermal` is not offered there.
