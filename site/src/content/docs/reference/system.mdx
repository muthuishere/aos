<p class="cmd-lead">Session power state: lock, sleep, restart, shutdown, logout</p>

6 commands. Run `aos system --help` for the same list from the binary, or [see every group](../commands/).

Session and power state. `info` prints OS and hardware facts and works everywhere. `lock`, `sleep`, `logout`, `restart` and `shutdown` do exactly what they say with no confirmation, so an agent should check with the person before the last three.

## Commands

### aos system info

<p class="cmd-lead">Print OS, host, and hardware facts</p>

```sh
aos system info
```

```sh
aos system info
```
