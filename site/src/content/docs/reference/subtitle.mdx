### aos subtitle show

<p class="cmd-lead">Show a film-style caption over everything (or over one app's window) for a few seconds</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos subtitle show <text...> [--seconds=<n>] [--app=<name> | --title=<s> | --monitor=<n> | --rect=<x,y,w,h>] [--position=bottom-center|top-center|center|left|right|top-left|top-right|bottom-left|bottom-right] [--margin=<px|N%>] [--offset=<dx,dy>] [--size=S|M|L|XL|<px>] [--color=<text colour>] [--bg=auto|none|<colour>] [--font=<name>] [--weight=regular|bold] [--align=left|center|right] [--max-width=<px|N%>] [--detach] [--wait] [--preview=<out.png>] [--json]
```

| flag | values | meaning |
|---|---|---|
| `<text...>` | | Required positional argument |
| `--seconds` | `<n>` | Optional |
| `--app` | `<name>` | Optional |
| `--title` | `<s>` | Optional |
| `--monitor` | `<n>` | Optional |
| `--rect` | `<x,y,w,h>` | Optional. comma-separated |
| `--position` | `bottom-center`, `top-center`, `center`, `left`, `right`, `top-left`, `top-right`, `bottom-left`, `bottom-right` | Optional |
| `--margin` | `px`, `N%` | Optional |
| `--offset` | `<dx,dy>` | Optional. comma-separated |
| `--size` | `S`, `M`, `L`, `XL`, `<px>` | Optional |
| `--color` | `<text colour>` | Optional |
| `--bg` | `auto`, `none`, `<colour>` | Optional |
| `--font` | `<name>` | Optional |
| `--weight` | `regular`, `bold` | Optional |
| `--align` | `left`, `center`, `right` | Optional |
| `--max-width` | `px`, `N%` | Optional |
| `--detach` |  | Optional |
| `--wait` |  | Optional |
| `--preview` | `<out.png>` | Optional |
| `--json` |  | Optional |

```sh
aos subtitle show "installing dependencies"
aos subtitle show "Now I'm opening Safari" --app=Safari --position=bottom
aos subtitle show "running the migration" --seconds=30 --position=top
aos subtitle show "step 1 of 3" --seconds=4 --wait
aos subtitle stop
# white on a translucent dark pill, bottom-center, 8% up; a new caption replaces the last
```
