<p class="cmd-lead">Power source detection and keep-awake</p>

4 commands. Run `aos power --help` for the same list from the binary, or [see every group](../commands/).

Whether the machine runs on mains power or battery. For charge level, see `battery`. `awake` keeps the machine from sleeping, for `--for=2h` or until `aos power awake off`; `--display` keeps the screen on too. It is held by a small child process (`caffeinate`, `systemd-inhibit`, or aos itself on Windows), so a crash or reboot never leaves the machine stuck awake.

## Commands

### aos power awake

<p class="cmd-lead">Keep the machine from sleeping, for a while or until `power awake off`</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)

```sh
aos power awake [--for=<duration>] [--display] [--json]
```

| flag | values | meaning |
|---|---|---|
| `--for` | `<duration>` | Optional |
| `--display` |  | Optional |
| `--json` |  | Optional |

```sh
aos power awake --for=2h
aos power awake --for=30m --display
aos power awake            # until `aos power awake off`
```

### aos power awake off

<p class="cmd-lead">End the keep-awake started by `power awake`</p>

Under WSL / SSH: runs inside WSL (where aos was started). [How the host works](../../host/)


