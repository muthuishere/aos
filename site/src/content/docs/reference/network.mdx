<p class="cmd-lead">Connectivity, addresses, and Wi-Fi</p>

7 commands. Run `aos network --help` for the same list from the binary, or [see every group](../commands/).

Connectivity facts: the active interface and its address, the joined Wi-Fi network, and the local IP on its own for scripts. No display needed. `public-ip` asks Cloudflare's trace endpoint (`1.1.1.1/cdn-cgi/trace`, no account) for the address the internet sees. `vpn status|on|off` drives the VPNs the OS itself manages (`scutil --nc` on macOS, NetworkManager on Linux, `rasdial` on Windows); VPN apps that run their own tunnel outside those settings do not show up.

## Commands

### aos network ip

<p class="cmd-lead">Print the local address of the active interface</p>

```sh
aos network ip
```

```sh
aos network ip         # 192.168.1.20
```

### aos network public-ip

<p class="cmd-lead">Print this machine's public IP address as the internet sees it</p>

```sh
aos network public-ip [--json]
```

| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh
aos network public-ip
aos network public-ip --json   # ip, country, source
```

### aos network status

<p class="cmd-lead">Print the active interface, address, and Wi-Fi network</p>

```sh
aos network status
```

```sh
aos network status
```

### aos network vpn off

<p class="cmd-lead">Disconnect a system VPN by name</p>

```sh
aos network vpn off <name>
```

| flag | values | meaning |
|---|---|---|
| `<name>` | | Required positional argument |

```sh
aos network vpn off "Work VPN"
```

### aos network vpn on

<p class="cmd-lead">Connect a system VPN by name</p>

```sh

```

| flag | values | meaning |
|---|---|---|
| `<name>` | | Required positional argument |

```sh
aos network vpn on "Work VPN"
```
