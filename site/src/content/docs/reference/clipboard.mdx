<p class="cmd-lead">Read and write the system clipboard</p>

9 commands. Run `aos clipboard --help` for the same list from the binary, or [see every group](../commands/).

Read and write the system clipboard as text. `copy` takes words or stdin, `paste` prints to stdout, so both sit naturally in a pipeline. To react to clipboard changes, use `aos watch clipboard`.

## Commands

### aos clipboard copy

<p class="cmd-lead">Copy stdin, or the given words, to the clipboard</p>

```sh
aos clipboard copy [text...]
```

```sh
echo hello | aos clipboard copy
aos clipboard copy "some text"
```

### aos clipboard history

<p class="cmd-lead">List the texts the history recorder saw, newest first</p>

```sh
aos clipboard history [--limit=<n>] [--json]
```

| flag | values | meaning |
|---|---|---|
| `--limit` | `<n>` | Optional |
| `--json` |  | Optional |

```sh
aos clipboard history
aos clipboard history --limit=5 --json
```

### aos clipboard history clear

<p class="cmd-lead">Delete the recorded clipboard history</p>

```sh
aos clipboard history clear
```

```sh
aos clipboard history clear
```

### aos clipboard history get

<p class="cmd-lead">Print history entry \<n\> (1 is the newest)</p>

```sh
aos clipboard history get <n>
```

| flag | values | meaning |
|---|---|---|
| `<n>` | | Required positional argument |

```sh
aos clipboard history get 2
```

### aos clipboard history restore

<p class="cmd-lead">Put history entry \<n\> back on the clipboard (1 is the newest)</p>

```sh
aos clipboard history restore <n>
```

| flag | values | meaning |
|---|---|---|
| `<n>` | | Required positional argument |

```sh
aos clipboard history restore 2
```

### aos clipboard history start

<p class="cmd-lead">Start recording clipboard history in the background (opt-in; ask the person first)</p>

```sh
aos clipboard history start
```

```sh
aos clipboard history start
```

<p class="cmd-lead">Say whether the history recorder is running and how much it holds</p>


| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh

```

### aos clipboard history stop

<p class="cmd-lead">Stop the clipboard history recorder (the history is kept)</p>

```sh
aos clipboard history stop
```

```sh
aos clipboard history stop
```

### aos clipboard paste

<p class="cmd-lead">Print the clipboard to stdout</p>

```sh
aos clipboard paste
```

```sh
aos clipboard paste > note.txt
```
