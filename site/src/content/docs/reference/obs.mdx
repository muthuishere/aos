<p class="cmd-lead">What this machine has been asked to do</p>

6 commands. Run `aos obs --help` for the same list from the binary, or [see every group](../commands/).

What this machine has been asked to do. Every command records one span with the route, the source (`cli` or `mcp`), the exit code, the duration and the number of arguments, never their values. `audit` lists commands in order, `stats` and `summary` aggregate, `tail` shows the latest, `export` emits OTLP JSON. See [observability](/aos/observability/).

## Commands

### aos obs audit

<p class="cmd-lead">Every command this machine was asked to run, oldest first</p>

```sh
aos obs audit [--since=<duration>] [--source=<cli|mcp>] [--failed] [--json]
```

| flag | values | meaning |
|---|---|---|
| `--since` | `<duration>` | Optional |
| `--source` | `cli`, `mcp` | Optional |
| `--failed` |  | Optional |
| `--json` |  | Optional |

```sh
aos obs audit --since=24h
aos obs audit --source=mcp     # only what agents asked for
aos obs audit --failed
```
