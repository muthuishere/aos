<p class="cmd-lead">Check that this machine can do what the commands promise</p>

1 command. Run `aos doctor --help` for the same list from the binary, or [see every group](../commands/).

One pass over what this machine can and cannot do, with the fix for each gap. It does real work: it round-trips the clipboard, takes a screenshot, lists windows, checks permissions and looks for ffmpeg. `--json` gives a list of checks with a `status` field, so a script can pick out what is not `ok`.

## Commands

### aos doctor

<p class="cmd-lead">Diagnose this installation and say how to fix what is broken</p>

```sh
aos doctor [--json]
```

| flag | values | meaning |
|---|---|---|
| `--json` |  | Optional |

```sh
aos doctor
```
