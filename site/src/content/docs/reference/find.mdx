### aos find

<p class="cmd-lead">Find text inside a window and print its global bounds and center</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos find (<app> | --app=<name> | --title=<substring>) --text=<text> [--source=auto|accessibility|ocr] [--role=<role>] [--exact] [--all] [--no-raise] [--json]
```

| flag | values | meaning |
|---|---|---|
| `<app>` | | One of these is required |
| `--app` | `<name>` | One of these is required |
| `--title` | `<substring>` | One of these is required |
| `--text` | `<text>` | Required |
| `--source` | `auto`, `accessibility`, `ocr` | Optional |
| `--role` | `<role>` | Optional |
| `--exact` |  | Optional |
| `--all` |  | Optional |
| `--no-raise` |  | Optional |
| `--json` |  | Optional |

```sh
aos find --app=Calculator --text=7
aos find Safari --text="Reload this page" --role=button --json
aos find --title=Settings --text=Wi-Fi --source=ocr --all
# exit 3 when the window or the text is not found
```
