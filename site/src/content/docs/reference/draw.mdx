<p class="cmd-lead">Point at something on screen with a big arrow and a sign</p>

9 commands. Run `aos draw --help` for the same list from the binary, or [see every group](../commands/).

Click-through drawings on the real screen for a person to follow: an arrow, ring or box with a sign at a point, a region, a window or a control found by its label, and `draw text` for a label with no arrow. Nothing takes focus and clicks pass through to the app underneath. `draw cover` is the opposite: an opaque box that hides a window, part of it or a token, and follows the window. See [arrows & pointers](/aos/drawing/arrows/), [text labels](/aos/drawing/text/) and [covers](/aos/drawing/covers/).

## Commands

### aos draw

<p class="cmd-lead">Draw a click-through arrow + sign at a point, region, window, text or the mouse</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

Under WSL / SSH: runs on the Windows host (the machine with the screen). [How the host works](../../host/)

```sh
aos draw (--at=<x,y> | --rect=<x,y,w,h> | <app> | --app=<name> | --title=<s> | --mouse) [--find=<text> [--role=<r>] [--source=<s>] [--exact] [--nth=<n>]] --text=<sign> [--style=arrow|ring|box] [--shape=bend|straight|zigzag|spiral] [--size=S|M|L] [--color=<name|#hex>] [--from=<side>] [--monitor=<n>] [--position=<side>] [--duration=<seconds>] [--detach] [--animate=on|off] [--preview=<out.png>] [--json]
```

| flag | values | meaning |
|---|---|---|
| `<app>` | | One of these is required |
| `--at` | `<x,y>` | One of these is required. comma-separated |
| `--rect` | `<x,y,w,h>` | One of these is required. comma-separated |
| `--app` | `<name>` | One of these is required |
| `--title` | `<s>` | One of these is required |
| `--mouse` |  | One of these is required |
| `--find` | `<text>` | Optional |
| `--role` | `<r>` | Optional |
| `--source` | `<s>` | Optional |
| `--exact` |  | Optional |
| `--nth` | `<n>` | Optional |
| `--text` | `<sign>` | Required |
| `--style` | `arrow`, `ring`, `box` | Optional |
| `--shape` | `bend`, `straight`, `zigzag`, `spiral` | Optional |
| `--size` | `S`, `M`, `L` | Optional |
| `--color` | `name`, `#hex` | Optional |
| `--from` | `<side>` | Optional |
| `--monitor` | `<n>` | Optional |
| `--position` | `<side>` | Optional |
| `--duration` | `<seconds>` | Optional |
| `--detach` |  | Optional |
| `--animate` | `on`, `off` | Optional |
| `--preview` | `<out.png>` | Optional |
| `--json` |  | Optional |

```sh
aos draw --app=Calculator --find=7 --style=ring --text="press 7"
aos draw --at=640,400 --text="click here" --duration=5
aos draw --rect=100,100,400,200 --style=box --text="this area" --preview=/tmp/draw.png
aos draw --mouse --text="you are here" --detach
aos draw stop
# exit 3 when --find does not find the window or the text
```

### aos draw cover

| flag | values | meaning |
|---|---|---|

| `--rect` | `<x,y,w,h>` | One of these is required. comma-separated |
| `--monitor` | `<n>` | One of these is required |
| `--app` | `<name>` | One of these is required |

| `--weight` | `regular`, `bold` | Optional |
| `--align` | `left`, `center`, `right` | Optional |
| `--position` | `center`, `top-left`, `...` | Optional |
| `--margin` | `px`, `N%` | Optional |

| `--border-color` | `<c>` | Optional |
| `--radius` | `<px>` | Optional |
| `--preset` | `<name>` | Optional |
| `--block-input` |  | Optional |
| `--no-follow` |  | Optional |
| `--id` | `<name>` | Optional |
| `--duration` | `<seconds>` | Optional |
| `--detach` |  | Optional |
| `--preview` | `<out.png>` | Optional |
| `--json` |  | Optional |

```sh
aos draw cover --app=Preview --detach --id=scan
aos draw cover --app=Mail --rect=0,0,30%,100% --preset=private --detach
aos draw cover --app=Terminal --find=ghp_ --pad=6 --color=#1e40af --text="Hidden by request" --detach
aos draw cover --rect=100,100,400,200 --block-input --detach --id=form
aos draw cover update --id=scan --preset=brb --text="Back in 5"
aos draw cover list
aos draw cover stop --id=scan
# window covers follow the window: move, resize, other monitor, hidden while minimised
# --detach keeps the cover until `draw cover stop` / `draw stop`; without it the cover shows for --duration (8s)
# presets: private, redacted, brb, plus "presets" in `aos draw config`
```
