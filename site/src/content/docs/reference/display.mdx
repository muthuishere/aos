<p class="cmd-lead">Attached monitors</p>

7 commands. Run `aos display --help` for the same list from the binary, or [see every group](../commands/).

Attached monitors. `list` prints each monitor with its geometry and which one is primary, active (has the pointer) and focused (has the frontmost window). `active` and `focused` print just the id, for scripts that pass it to `--monitor`. Monitor numbers can change when displays are plugged in or out. `modes` lists the resolutions a monitor supports; `mode` switches to one (the exact size, the highest refresh rate unless `@Hz` is given, and anything else is refused with the list); `mirror on|off` mirrors every monitor to the main one or extends the desktop again. On macOS changes last for the login session; on Linux they go through `xrandr`. `brightness` prints or sets the screen's brightness on a 0-100 scale, with `+10` / `-10` for relative steps like `audio volume`; it drives the built-in panel when there is one (external monitors through DDC/CI on Windows) and exits 2 when the display has no software brightness.

## Commands

### aos display active

<p class="cmd-lead">Print the ID of the monitor the pointer is on</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos display active
```

```sh
aos capture screenshot --monitor=$(aos display active)
```

### aos display brightness

<p class="cmd-lead">Print or set screen brightness 0-100 (the built-in panel, else the main display)</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos display brightness [<0-100>|+<n>|-<n>]
```

| flag | values | meaning |
|---|---|---|
| `<0-100>` | | Optional positional argument |
| `<n>` | | Optional positional argument |
| `<n>` | | Optional positional argument |

```sh
aos display brightness       # 70
aos display brightness 50
aos display brightness -10
```

### aos display focused

<p class="cmd-lead">Print the ID of the monitor holding the frontmost window</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos display focused
```

```sh
aos window move Chrome --monitor=$(aos display focused)
```

### aos display mirror

<p class="cmd-lead">Mirror every monitor to the main one (on) or extend the desktop (off)</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos display mirror on|off
```

```sh
aos display mirror on
aos display mirror off
```

### aos display mode

<p class="cmd-lead">Switch a monitor to a resolution (highest refresh unless @Hz is given)</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos display mode <monitor id> <WxH[@Hz]>
```

| flag | values | meaning |
|---|---|---|
| `<monitor id>` | | Required positional argument |
| `<WxH[@Hz]>` | | Required positional argument |

```sh
aos display mode 2 2560x1440
aos display mode 1 1920x1080@60
```

### aos display modes

<p class="cmd-lead">List the resolutions and refresh rates a monitor supports</p>

<p class="cmd-badges"><span class="cmd-badge gui">needs a display</span></p>

```sh
aos display modes <monitor id> [--json]
```

| flag | values | meaning |
|---|---|---|
| `<monitor id>` | | Required positional argument |
| `--json` |  | Optional |

```sh
aos display modes 1
aos display modes 2 --json
```
