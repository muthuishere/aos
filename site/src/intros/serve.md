Serve things over HTTP. `mcp` exposes every available non-blocking command as a typed tool on loopback, guarded by a per-run or pinned token (see [using it from an agent (MCP)](/aos/mcp/)); `tools` previews the catalogue without starting a server. `files` serves a folder read-only with listings, on loopback or, with `--lan`, behind a random token for a phone on the same Wi-Fi (see [serving files](/aos/serve-files/)).
