An app's menu bar as a searchable list of commands, read through macOS accessibility: `list` prints every item as a path such as `File > Export as PDF…` (the frontmost app unless `--app` names one), and `run` presses one. An exact path always wins; otherwise the text must match exactly one path, and an ambiguous match is refused with the candidates listed, because running the wrong command cannot be undone. Menus are read and pressed without being opened. Needs the Accessibility permission. Windows and Linux exit 2 for now.
