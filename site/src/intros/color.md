Read the color of one pixel on screen as hex and RGB. `at` takes global screen points, the same coordinates as `mouse` and `capture screenshot --region`, so negative x reaches a monitor to the left. `pick` samples under the mouse pointer, with an optional `--delay` so the person can move the pointer onto the color first. It reads through the same capture path as screenshots, so on macOS it needs Screen Recording permission; without it, every pixel reads as black.
