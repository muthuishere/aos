Session and power state. `info` prints OS and hardware facts and works everywhere. `lock`, `sleep`, `logout`, `restart` and `shutdown` do exactly what they say with no confirmation, so an agent should check with the person before the last three. `thermal` prints how hard the OS is throttling to stay cool (macOS: nominal, fair, serious, critical) and the temperatures it exposes: the battery on macOS, where die temperatures sit behind the private SMC, and every thermal zone on Linux. Windows keeps temperatures behind WMI, so `thermal` is not offered there. `load` samples CPU for half a second and prints busy % overall and per core plus the 1/5/15-minute load averages (Windows has none); `uptime` prints how long the machine has been up and when it booted. `memory` reports total, used, available and free RAM plus swap; *available* is the number that answers "how much memory is left", since idle RAM is used as cache and *free* is usually small.
