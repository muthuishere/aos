Session and power state. `info` prints OS and hardware facts and works everywhere. `lock`, `sleep`, `logout`, `restart` and `shutdown` do exactly what they say with no confirmation, so an agent should check with the person before the last three. `load` samples CPU for half a second and prints busy % overall and per core plus the 1/5/15-minute load averages (Windows has none); `uptime` prints how long the machine has been up and when it booted.
