Session and power state. `info` prints OS and hardware facts and works everywhere. `lock`, `sleep`, `logout`, `restart` and `shutdown` do exactly what they say with no confirmation, so an agent should check with the person before the last three. `load` samples CPU for half a second and prints busy % overall and per core plus the 1/5/15-minute load averages (Windows has none); `uptime` prints how long the machine has been up and when it booted. `memory` reports total, used, available and free RAM plus swap; *available* is the number that answers "how much memory is left", since idle RAM is used as cache and *free* is usually small.
