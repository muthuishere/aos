Output volume and mute for the system sound device. `volume` with no argument prints the level 0 to 100; with a number it sets it, and `+n` or `-n` nudges it. `mute` prints or changes the mute state. These work without a display, so they are fine over SSH. `devices` lists every output and input device with the defaults marked; `output` and `input` print the current default, or switch it by name, a unique part of the name, or id (an ambiguous name is refused with the candidates).
