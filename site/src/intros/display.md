Attached monitors. `list` prints each monitor with its geometry and which one is primary, active (has the pointer) and focused (has the frontmost window). `active` and `focused` print just the id, for scripts that pass it to `--monitor`. Monitor numbers can change when displays are plugged in or out. `modes` lists the resolutions a monitor supports; `mode` switches to one (the exact size, the highest refresh rate unless `@Hz` is given, and anything else is refused with the list); `mirror on|off` mirrors every monitor to the main one or extends the desktop again. On macOS changes last for the login session; on Linux they go through `xrandr`. `brightness` prints or sets a monitor's brightness on a 0-100 scale, with `+10` / `-10` for relative steps like `audio volume`. With no id it acts on the monitor holding the focused window (else the one under the pointer) and prints which one changed, e.g. `BenQ GW2785TC (2): 64`. It drives the built-in panel and external monitors over DDC/CI (IOAVService on Apple Silicon Macs, dxva2 on Windows, `ddcutil` on Linux when installed); every write is read back. `--all` sets every monitor, `--list` shows each monitor's name, value and whether it can be controlled, and `--json` gives `{monitor, name, value, method}`. A monitor that cannot be controlled, or a sleeping built-in panel, exits 2 with the reason. `of --app <name>` or `of --window <id>` prints the monitor that window is on, with its name and brightness. `list` also shows each monitor's name as the OS reports it.
