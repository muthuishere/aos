Wait for something to happen on this machine. With a condition (`--match`, `--gone`, `--until`, `--exit`, `--for`, `--below`) a watch exits 0 when it is met and 3 on `--timeout`, so an agent chains the next step with `&&`. Without one it prints one JSON line per event until interrupted. The first sample is a baseline, so `--max=1` means the next change; `watch clipboard` hides the text unless `--content` is passed. Watches are blocking, so they are not MCP tools. For mail, Teams, WhatsApp or calendar events use apl. See [waiting for things](/aos/watching/).
