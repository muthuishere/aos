Do Not Disturb, called Focus on macOS and Windows. `status` reads it on macOS (a Focus turned on by hand, from the Focus store; scheduled ones are not visible there) and on GNOME. `on` and `off` work on GNOME, where `--for=1h` turns banners back on by itself. macOS and Windows offer no supported API to set Focus, so there they exit 2 and say what to use instead. It follows the host: it is about the person at the screen.
