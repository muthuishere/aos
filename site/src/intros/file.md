Read, write and inspect files with exit codes an agent can trust. `read` takes a line range, `write` and `append` take words or stdin, `list` and `stat` have `--json`. `delete` refuses filesystem roots, your home directory and system directories, and needs `--recursive` for a directory. `recent` lists the documents the person opened lately, newest first, from the OS's own recents: macOS Recent Documents (per-app lists with `--app`, matched against the bundle id), the freedesktop `recently-used.xbel` on Linux (with `--app`), and the shortcuts in the Windows Recent folder (no `--app` there). It follows the host, because it is about the person's desktop.
